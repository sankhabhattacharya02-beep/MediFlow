# MediFlow — Smart Hospital Waiting Time Predictor

MediFlow is a beginner-friendly machine learning project that estimates how long a patient may wait to see a doctor after triage. It uses a trained Random Forest model and a simple Streamlit dashboard to collect patient details and display a predicted waiting time in minutes.

> **Note:** This project uses a synthetic (artificially generated) dataset. Predictions are estimates for demonstration purposes only and are not guaranteed hospital waiting times.

---

## Model Inputs

The trained model uses exactly five inputs to make a prediction:

| Input | Description |
|-------|-------------|
| **Triage Category** | Urgency level assigned by the triage nurse (e.g. Urgent, Non-urgent) |
| **Department** | Clinical department the patient is assigned to (e.g. Cardiology, Emergency) |
| **Facility Occupancy Rate** | How full the hospital is, from 0.0 (empty) to 1.0 (fully occupied) |
| **Providers on Shift** | Number of doctors currently on duty |
| **Nurse to Triage Complete Time (minutes)** | How long the triage assessment took, in minutes |

## Getting Started

### 1. Install dependencies

Run this command in your terminal from the project folder:

```bash
python -m pip install -r requirements.txt
```

### 2. Train the model (first time only)

This generates `wait_time_model.pkl` and `model_feature_columns.pkl`:

```bash
python app.py
```

### 3. Run the dashboard

```bash
python -m streamlit run Dashboard.py
```

Then open the local URL shown in your terminal (usually `http://localhost:8501`).

## Project Files

| File | Purpose |
|------|---------|
| `app.py` | Loads the dataset, trains the model, and saves it to disk |
